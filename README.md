# Glücksrad Studio

Eine browserbasierte App zum Erstellen, Speichern und Drehen individueller Glücksräder.

## Funktionen

- Bis zu 30 Felder
- Individuelle Namen und Farben
- Lokale Speicherung im Browser
- Ton beim Wechsel zum nächsten Feld
- Konfetti-Animation
- Gewinnerfeld direkt entfernen

## Starten

Die Datei `index.html` direkt im Browser öffnen oder die Website über einen lokalen Webserver bereitstellen.
